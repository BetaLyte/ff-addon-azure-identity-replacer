# Azure Identity Replacer add-on 
Quick'n'dirty WebExtension add-on for Firefox and Chromium based browsers to replace username, tenant and icon in the top right corner on Azure Portal.

## Installation
### Firefox Developer / Nightly
Can be loaded in Firefox Developer and Nightly editions by loading the manifest in about:debugging

### Firefox
Can be installed in Firefox by running the signed .XPI

### Chrome
Can be installed in Chrome by dragging the signed .CRX to `chrome://extensions` or by following the steps below:

1. Clone / download this repo
2. Open chrome://extensions
3. Enable Developer mode
4. Click "Load unpacked"
5. Select the folder containing the files

## Configuration
Configure preferences in Extension Settings.
